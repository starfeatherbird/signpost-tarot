# 상징 스톤 이미지 생성 프롬프트

결과 PNG 19장을 `app/stone_source/` 에 **파일명 = 스톤 id** 로 저장한 뒤 `npm run stones` 를 실행하면 앱에 반영됩니다.

- **단색 배경(검정 권장)으로 뽑아도 됩니다.** 변환 스크립트가 네 모서리 색을 배경으로 보고 지우며, 배경과 맞닿은 외곽 1~3px 띠는 배경색이 섞인 비율을 역산해 걷어 냅니다(디프린지). 밝은 테마에서 돌 둘레에 검은 선이 남지 않도록 검증했습니다.
- 투명 배경 PNG 면 배경 처리 없이 여백만 정리합니다.
- 실제 제작·검수는 별도 Claude 프로젝트(스톤 제작 방)에서 Midjourney 프롬프트로 진행합니다. 아래는 Claude Design 용 초안입니다.

---

타로 상담 앱 "이정표"에 들어갈 **상징 스톤(원석) 아이콘 19종**을 만들어 주세요.

**용도**
- 상담 결과 화면에서 48px, 수집 화면에서 36px 크기로 보입니다. 작게 봐도 돌마다 색과 형태가 구분되어야 합니다.
- 앱 배경은 짙은 남색(#0F1A2E) 기본이고 밝은 테마(#F5F7FB)도 있으니, 두 배경 모두에서 잘 보이게 해 주세요.
- 포인트 컬러는 #1D559C 이지만 돌 자체는 각자의 실제 색을 따릅니다.

**공통 스타일**
- 19장 모두 같은 화풍: 반투명한 질감이 느껴지는 단순화된 텀블 스톤(둥글게 다듬은 원석) 한 개, 정면 약간 위에서 본 모습, 부드러운 한 방향 조명, 은은한 하이라이트, 돌 아래 옅은 그림자 하나.
- 배경은 **투명(PNG, 알파)**. 테두리·글자·장식·반짝임 효과 없음.
- 각 장은 정사각형 1024×1024, 돌이 화면의 약 75%를 차지하고 여백은 사방 같게.
- 사실적인 광물 사진이 아니라 정돈된 일러스트 느낌. 과한 채도나 네온 금지.

**19종 (파일명 · 이름 · 색과 질감 지시)**
1. `moonstone.png` · 문스톤 · 우윳빛 흰색에 푸른 광채가 살짝 비치는 반투명
2. `rose-quartz.png` · 로즈쿼츠 · 연한 분홍, 뿌연 반투명
3. `amethyst.png` · 자수정 · 보라색, 안쪽에 더 진한 보라 결
4. `citrine.png` · 시트린 · 맑은 노란색~호박색, 투명감
5. `black-tourmaline.png` · 블랙 투어멀린 · 검은색, 세로 결이 있는 불투명, 약한 금속광
6. `clear-quartz.png` · 백수정 · 무색 투명, 안쪽에 옅은 흰 안개
7. `tiger-eye.png` · 타이거아이 · 갈색과 금색 띠가 번갈아 흐르는 비단결 광택
8. `lapis-lazuli.png` · 라피스 라줄리 · 진한 군청색, 금색 작은 점(황철석) 몇 개
9. `aventurine.png` · 아벤츄린 · 녹색, 미세한 반짝 입자
10. `carnelian.png` · 카넬리안 · 주황~붉은 갈색, 반투명
11. `jade.png` · 제이드 · 차분한 녹색, 매끈하고 살짝 반투명
12. `aquamarine.png` · 아쿠아마린 · 맑은 하늘색, 투명
13. `amazonite.png` · 아마조나이트 · 청록빛 민트색, 흰 줄무늬 조금, 불투명
14. `larimar.png` · 라리마 · 하늘색과 흰색이 물결처럼 섞인 불투명
15. `labradorite.png` · 라브라도라이트 · 회청색 바탕에 파랑·초록·금빛 광채가 비스듬히 번쩍이는 면
16. `garnet.png` · 가넷 · 짙은 와인색, 투명감
17. `pietersite.png` · 피터사이트 · 남색·회색·금갈색이 폭풍처럼 소용돌이치는 비단결 광택
18. `selenite.png` · 셀레나이트 · 흰색, 세로로 결이 뚜렷한 반투명 막대 모양(다른 돌과 달리 길쭉해도 됨)
19. `obsidian.png` · 흑요석 · 유리처럼 매끈한 검정, 가장자리가 살짝 비쳐 보이는 반투명 검정

각 장을 개별 PNG 로 내보내 주세요. 파일명은 위 목록 그대로 써 주세요.
