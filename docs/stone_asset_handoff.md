# 이정표 상징 스톤 이미지 처리 요청

`stone_source/` → `app/stone_asset/`

## 0. 요약

- 타로 상담 앱 "이정표"의 결과마다 나오는 상징 스톤 19종 원본 이미지가 `stone_source/`에 있다.
- 원본은 미드저니로 생성한 1024×1024 PNG이고, 모두 단색 검정 배경이다.
- 이것을 **투명 배경 에셋**으로 가공해 `app/stone_asset/`에 넣는다.
- 같은 처리를 나중에 다시 돌릴 수 있도록 **재실행 가능한 스크립트**로 남긴다. 스톤 추가·교체가 예정되어 있다.
- 표시 크기는 결과 화면 48px, 수집 화면 36px이다. 작게 줄여도 돌끼리 구분되는 것이 최우선이다.
- 앱 배경은 기본 테마 `#0F1A2E`(짙은 남색), 밝은 테마 `#F5F7FB`이다.

## 1. 시작 전에

- 먼저 프로젝트 구조를 살펴보고, 기존 이미지 로딩 방식과 빌드 방식에 맞춰 출력 형식(해상도, 포맷, 파일명 규칙)을 정해 줘. 아래 출력 사양은 기본안이고, 프로젝트 관례와 다르면 관례를 따르되 무엇을 바꿨는지 알려 줘.
- `stone_source/`는 원본 보관 폴더다. **절대 덮어쓰거나 수정하지 말 것.** 중간 산출물은 별도 작업 폴더(예: `stone_work/`)에 둔다.

## 3. 처리 순서

### 3-1. 돌별 전처리 (원본 1024px 상태에서, 배경 제거 전에)

**clear-quartz: 좌우 반전**

- 하이라이트가 오른쪽에 맺혀 있어서, 다른 돌들과 조명 방향(좌상단)을 맞추기 위한 처리다.
- PIL 기준 `ImageOps.mirror()`.

**obsidian: 반점 제거 → 대각선 반사 (이 순서대로)**

① 반점 제거

- 원본 몸통에 미세한 흰 점이 약 7천 개 박혀 있다. 흑요석은 흠 없는 검은 유리여야 하므로 제거한다.
- 점들이 서로 떨어진 고립형이라, 주변 색으로 메우면 흔적이 남지 않는다. 검증된 파라미터는 아래와 같다.

```
돌 마스크: 밝기(RGB 평균) > 14 → binary closing 10회 → 구멍 채우기 → 가장 큰 연결 영역만
작업 영역(inner): 마스크를 10px 침식한 영역 (가장자리의 적갈색 테두리 보호)
하이라이트 보호: 밝기 > 100 → opening 3회 → 5px 팽창한 영역은 건드리지 않음

2회 반복:
  1차: 채널별 median filter 크기 7, 임계값 8, 연결 영역 크기 ≤ 20px
  2차: 채널별 median filter 크기 11, 임계값 8, 연결 영역 크기 ≤ 40px
  각 회차:
    점 후보 = (밝기 - median 밝기 > 임계값) & inner & ~하이라이트 보호
    크기 조건을 만족하는 연결 영역만 남기고 1px 팽창
    해당 픽셀을 median 색으로 교체

검증 지표 (마스크 20px 침식 영역 기준):
  (밝기 - median7 밝기 > 30) & (밝기 < 150) 픽셀 비율
  처리 전 약 15/1000 → 처리 후 약 0.6/1000 이면 정상
```

② 대각선 반사

- 세로 타원을 가로 타원으로 바꾸기 위한 처리다. 짝이 되는 블랙 투어멀린이 세로 기둥형이라, 실루엣이 겹치지 않게 한다.
- **90도 회전이 아니라 주대각선 기준 반사**다. PIL 기준 `Image.TRANSPOSE`.
- 회전하면 좌상단 하이라이트가 다른 모서리로 가지만, 주대각선 반사는 좌상단 빛을 좌상단에 그대로 둔다.

참고: 위 두 단계를 적용한 참조 결과물 `obsidian_reference.png`를 함께 전달한다. 스크립트 결과가 이 파일과 거의 같으면 정상이다.

### 3-2. 배경 제거

- **반드시 피사체 윤곽 인식(세그멘테이션) 방식으로 할 것.** 예: rembg(`isnet-general-use` 또는 `u2net`) 등.
- **밝기 기준으로 검정을 빼는 방식은 쓰지 말 것.** 자수정, 타이거아이, 가넷, 라브라도라이트, 피터사이트, 블랙 투어멀린, 흑요석은 몸통 안쪽에 검정에 가까운 영역이 있어서 구멍이 뚫린다.
- 알파 후처리:
  - 가장 큰 연결 영역만 남기고, 떨어져 나간 작은 조각(바닥 흔적, 잡티)은 제거한다.
  - **알파 내부의 구멍을 채운다.** 반투명한 돌(백수정, 시트린, 카넬리안, 제이드, 아쿠아마린, 가넷)도 앱에서는 속이 비치면 안 된다. 원본이 검정 위에서 렌더링되어 속에 검정이 이미 섞여 있으므로, 알파는 내부를 불투명(255)으로 두고 가장자리만 1~1.5px 부드럽게 한다.

### 3-3. 테두리 정리 (디프린지)

- 검정 배경에서 뽑은 이미지라, 배경을 제거하면 외곽 1~2px에 검은 기운이 남는다. 남색 테마에서는 안 보이지만 밝은 테마에서는 돌 둘레에 가는 검은 선으로 보인다.
- 배경이 순수한 검정(0,0,0)이었으므로 가장자리 픽셀은 `돌 색 × α`로 섞여 있다. **가장자리 픽셀의 RGB를 α로 나눠 원래 색을 복원**하는 방식(색 오염 제거)을 먼저 적용하고, 그래도 검은 선이 남으면 알파를 1px 침식한다.
- 블랙 투어멀린의 흰 테두리광, 흑요석의 적갈색 얇은 테두리는 돌의 일부이니 지워지지 않게 확인할 것.

### 3-4. 크기 정규화 (면적 기준, 긴 변 상한 90%)

- 각 돌을 알파 경계에 맞춰 잘라낸다.
- 19종 모두 **캔버스 안에서 돌이 차지하는 면적 비율이 같도록** 크기를 맞춘다. 목표 면적 비율은 약 0.37이다. 이는 긴 변을 캔버스의 72%로 맞췄을 때 19종의 중앙값이다.
  - `scale = sqrt(0.37 × 캔버스면적 / 돌 알파 면적)`
  - 단, 스케일 후 돌의 긴 변이 **캔버스의 90%를 넘지 않도록** 상한을 둔다. 셀레나이트(가는 막대)가 이 상한에 걸리는데, 의도된 동작이다.
- 돌을 캔버스 중앙(경계 상자 중심 기준)에 배치한다.
- 이유: 긴 변 기준으로 맞추면 가늘거나 긴 돌(셀레나이트, 제이드, 아쿠아마린, 블랙 투어멀린)은 작아 보이고, 사각형 돌(로즈쿼츠, 아마조나이트)은 커 보인다. 면적 기준이 수집 화면에서 시각적 무게를 가장 고르게 만든다는 것을 비교로 확인했다.

### 3-5. 내보내기

- 기본안: 정사각 투명 캔버스 256×256 PNG + 같은 크기 WebP(알파 포함).
  - 48px 표시의 3배 밀도(144px)까지 여유 있게 커버한다.
  - 프로젝트 관례가 있으면 그에 맞출 것.
- 파일명은 원본과 동일하게 유지한다(`moonstone.png` 등).
- 정규화 전 단계의 1024px 투명 마스터도 작업 폴더에 남겨 두면, 나중에 다른 크기로 다시 뽑을 때 편하다.
- **그림자는 이미지에 넣지 말 것.** 테마별 그림자는 코드에서 입힌다.
  - 참고안: 기본 테마 `drop-shadow(0 1px 3px rgba(0,0,0,.45))`, 밝은 테마 `drop-shadow(0 1px 2px rgba(15,26,46,.18))`.
- 처리 이력을 남기는 매니페스트(예: `stone_asset/manifest.json`)를 함께 만든다.
  - 항목: 파일명, 원본 경로, 적용한 처리(mirror / despeckle / transpose), 스케일 값, 처리 일시.
  - 나중에 스톤을 교체하거나 재처리할 때 반전·보정 누락을 막기 위해서다.

## 4. 검수 산출물 (처리 후 반드시 만들어서 보여 줄 것)

- 19종을 한 장에 나열한 **미리보기 시트**. 조합은 두 테마(`#0F1A2E`, `#F5F7FB`) × 두 크기(48px, 36px), 확인용 2배 확대본 포함.
- 아래 항목을 스스로 점검하고 결과를 보고해 줘.
  1. 몸통 안에 구멍이 뚫린 돌이 없는가. 짙은 색 돌 7종을 특히 확인.
  2. 밝은 테마에서 돌 둘레에 검은 선(프린지)이 남은 돌이 없는가.
  3. 돌 아래나 옆에 바닥 흔적, 떨어진 조각이 남지 않았는가.
  4. clear-quartz의 하이라이트가 왼쪽 위에 있는가(반전 확인).
  5. obsidian이 가로 타원이고, 하이라이트가 왼쪽 위에 있으며, 표면에 흰 점이 없는가.
  6. 19종의 크기가 시각적으로 고른가.

## 5. 하지 말 것

- `stone_source/` 원본 수정
- 밝기 기준 배경 제거
- 이미지에 그림자, 광택, 테두리 효과 추가
- 색 보정, 채도 조정, 샤프닝 등 돌의 모습을 바꾸는 보정 (3-1의 지정된 처리만 허용)
- 회전 (obsidian은 회전이 아니라 대각선 반사)

## 6. 범위 밖
